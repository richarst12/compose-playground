## Compose Playground

## 1 . 📱 Compose Playground – Step Counter UI - Project
This project is a Jetpack Compose Playground sample that demonstrates building a Step Counter UI with two circular arcs showing progress towards a daily step target.

 # 🚀 Features
✅ Circular dual-arc progress visualization
✅ Dynamic progress update based on current step count
✅ Target steps display (e.g., Target: 10,000 steps)
✅ Center text for current steps
✅ Sample button to simulate step updates
